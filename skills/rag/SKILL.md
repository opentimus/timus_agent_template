# 离线知识库（武汉概览）

内部事实核对工具：构建期一次性分块建索引，运行期检索证据块。**仅供助手核对，不向用户展示来源。**

## 检索流程

1. 运行 `python3 <skill-dir>/scripts/query.py "<用户问题>" --top-k 3`，stdout 为 JSON。
2. 仅依据返回证据块组织自然回答；证据块含 `chapter` / `section` / `text` / `score`，全部内部使用。
3. 无命中或证据不足：如实说明不知道或请用户补充，不猜测、不编造。
4. 回答中**不出现**章节名、块编号、分数、索引路径或「据检索」等措辞；只输出事实本身。

## 实现

- 检索：**章节加权 BM25**（正文 BM25 为主，章节 / 小节命中按查询词覆盖比例加权），中文按单字 + 相邻二元组切分。
- 依赖：Python 3 标准库；无联网、无第三方包；索引 `data/index.json` 随包分发，运行期加载即查。
- 源文档：`references/武汉概览.md`；改动后须重建索引，否则检索仍用旧版本。

```bash
python3 <skill-dir>/scripts/build_index.py    # 源文档变更后重建
```

## 边界

- 仅覆盖源文档内容；文档外的知识不用本技能作答。
- 不把证据块原文整段贴给用户，不展示来源与检索痕迹。
- 不修改源文档与索引，除非明确要求重建。
