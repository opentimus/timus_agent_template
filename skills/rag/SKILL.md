# 离线知识库（示例）

**示例技能**：源文档与检索逻辑绑定 `references/` 下的示例语料，复制专家包后删除或整体替换本技能，勿带入无关领域数据。

内部事实核对工具：运行期即时分块检索证据块，**仅供助手核对，不向用户展示来源**。

## 检索

1. 运行 `python3 <skill-dir>/scripts/query.py "<问题>" --top-k 3`，stdout 为 JSON（`chapter` / `section` / `text` / `score`）。
2. 仅依据证据块自然作答；无命中或证据不足如实说明，不猜测、不编造。
3. 回答中不出现章节名、块编号、分数、索引路径或「据检索」等措辞。
4. 仅覆盖源文档内容；不整段贴原文、不修改源文档（除非明确要求）。

## 实现

章节加权 BM25（正文为主，章节 / 小节按查询词覆盖比例加权），中文按单字 + 相邻二元组切分；Python 3 标准库，无联网、无第三方包、无预建索引，改源文档即生效。
