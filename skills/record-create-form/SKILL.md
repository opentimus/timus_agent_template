# 通用记录建档（任意表，一步到位）

按语义包登记的表新建记录，**不绑定具体实体**：表名、字段名、固定值、采集顺序均运行时判定，不硬编码。

采集、确认两步法、逐条写入与部分失败遵循 `timus-app-schema`「录入与维护技能的通用规范」与 `references/write-contract.md`；本文件只写「怎么把一张表建成可用流程」。

## 触发条件

「建 / 新增 / 录入 / 创建 / 提交 / 登记」+ 表名（或明确业务对象）。单条或多条（同组关联值）；只新建，不改既有；查 / 改 / 删走 `record-maintenance`。不查重、不覆盖。

## 第一步：锁定目标表

按 `timus-app-schema/references/intent-routing.md`「表定位规则」匹配 `tables`：

- 完全同名 / 唯一子串 → 锁定。
- 多张命中 → 弹窗选表。
- 零命中 → 列可用表请用户指定，不造表名、不跨表猜。
- 语义包仍为占位符 → 停，先索取应用编码与字段清单。

## 第二步：从语义包推导字段清单

读 `fields.<表>`，按 `type_policy` 分四组——**唯一分组依据**：

| 组 | 判定 | 处理 |
| --- | --- | --- |
| 不写组 | `AutoNumber` / `CreatedTime` / `Lookup` / `User` / `Formula` | 不进 `fields`、不进清单（除非用户要看） |
| 固定组 | 本技能固定值 | 预置值，不问，清单标「固定」 |
| 关联组 | `Text` 且名如 `S.<实体>ID` | `apaas_page_records` 查候选 → 弹窗；或上游继承 |
| 待采集组 | 其余 `Text` / `Number` / `SingleSelect` / `DateTime` | 按通用规范分类处理 |

必填：用户原话未给且语义包无可推导默认值者逐项确认；缺失即剔除该条并说明「第 N 条缺 XX 已跳过」，不臆造、不写空占位。

## 第三步：采集顺序（有关联依赖时）

层级依赖（如客户 → 项目 → 交付单元）由用户语义与候选引用关系决定：

1. 父级先于被引用者（有 `S.<实体>ID` 指向）。
2. 同层按语义包 `fields` 声明顺序。
3. 自由文本跟随最近关联字段同轮采集。

**无依赖多条**：同批共用关联值，逐条只差自由文本。
**有依赖多条**：若一批分属不同父级，提示分批，不静默拆。

## 第四步：数值与日期

- `Number`：`point_util.py normalize <值>` 取 `text`（两位小数）与 `value`（写入值）；总量语义用 `point_util.py split --total T --weight ...`，Σ=T 且逐条 ≥0.01。
- `DateTime`：`date_util.py options` 候选 → `batch` / `single` 出 `*_datetime`；禁手拼格式、禁心算星期。
- 单号类 `Text`（用户未给）：`point_util.py next-pair`（一对）/ `next-batch`（多条）。

## 第五步：正文清单 + 精简确认框

两步法：摘要行（目标表 + 共用关联值 + 条数）+ 明细表（序号 + 各采集字段，固定值标「固定」，敏感值脱敏）+ `即将写入「<表名>」表，共 N 条，确认提交？`。

## 第六步：写入与回报

- 逐条构造 `apaas_add_record`（无批量端点）；无依赖同轮并行，有依赖按序串行。
- 全部成功：回报「主标识 → 记录 ID」+ 成功条数；`traceId` 有效时一并回报。
- 部分失败：按 `write-contract.md`「部分失败」处理，不重试、不静默补写。

## 禁止事项

- 不为「确认字段结构」多查表（字段来自语义包）。
- 不凭记忆填关联 ID、不手写表名、不跨表猜字段。
- 不把字段明细堆进弹窗；不以任何理由跳过正文清单 + 弹窗。
- 不写只读字段、不改既有记录、不绕过连接器直连 REST。
- 语义包未填充时不进入写入流程。

## 示例（通用骨架，不绑业务）

用户：「新建一条 <表>，<名称> 是 XXX，<关联对象> 选 A，数量 6.567」
→ 锁表 → 推导字段 → 关联查候选并弹窗（首句已给则精确匹配）→ `normalize 6.567` → 正文清单 + 精简确认框 → 写入 → 回报 ID。

用户：「批量建 3 条 <表>，都是同一个 <关联对象>」
→ 解析 3 条自由文本 → 关联共用 → 缺项按条剔除并说明 → 一步确认写入。
