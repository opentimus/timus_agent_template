# 意图路由（查 / 改 / 删，唯一权威源）

查 / 搜 / 列出 / 详情 / 看一下 → 查询；改 / 修改 / 更新 / 修正 / 改成 → 修改；删 / 删除 / 移除 / 删掉 → 删除。三者均归 `timus-app-maintenance`，命中即执行、不确认动作类型；含糊（如「处理一下这条记录」）先弹 `AskUserQuestion` 选动作。添加 / 新增 / 录入 / 批量添加归 `timus-app-add`，由外层 `agents/*.md` 识别，本表不含。

## 表定位规则

按表头元数据 `tables` 表单名匹配：①完全同名 → 命中；②用户词为表名子串（如「流水」→「收入流水」）且唯一命中 → 命中；③多张 → 弹窗选，不猜；④零命中 → 列可用表名请用户指定，不造表名。

## 能力边界

写入仅覆盖表头元数据登记的表与字段；取值先本地基础数据，未命中再远程。表头元数据或基础数据仍为占位符 → 禁写入，先索取应用编码与字段清单落盘后操作。分析结论不冒充写入；查询结果足够时只回报，不臆造写回。
