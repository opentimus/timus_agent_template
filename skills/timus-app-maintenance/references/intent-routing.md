# 意图路由与定位（唯一权威源）

## 动作族

- 查 / 搜 / 列出 / 详情 / 看一下 → 查询；改 / 修改 / 更新 / 修正 / 改成 → 修改；删 / 删除 / 移除 / 删掉 → 删除。归 `timus-app-maintenance`，命中即执行、不确认动作类型。
- 添加 / 新增 / 录入 / 批量添加 → `timus-app-add`。
- 含糊意图（如「处理一下这条记录」）先 `AskUserQuestion` 选动作。

## 定位顺序

1. **应用**：本地应用名 / `app_name` 匹配。完全同名 → 唯一子串 → 多项弹窗 → 零命中列候选；不跨应用。
2. **表**：只在该应用 `tables` 中匹配，同上四级；不去别的应用找。
3. **字段**：只取该应用 `fields.<表>` 登记的系统字段名，逐字使用；未知字段拒绝。

## 边界

写入仅覆盖语义包登记的应用、表与字段；`app_name` 为占位符（`TODO*` / `<...>`）时先索取真实编码与字段清单落盘，禁写入。分析结论不冒充写入。
