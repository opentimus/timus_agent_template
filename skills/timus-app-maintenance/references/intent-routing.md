# 意图路由与定位（唯一权威源）

## 动作族

- 查 / 搜 / 列出 / 详情 / 看一下 → 查询；改 / 修改 / 更新 / 修正 / 改成 → 修改；删 / 删除 / 移除 / 删掉 → 删除。归 `timus-app-maintenance`，命中即执行、不确认动作类型。
- 添加 / 新增 / 录入 / 批量添加 → `timus-app-add`。
- 含糊意图（如「处理一下这条记录」）先 `AskUserQuestion` 选动作。

## 定位顺序

1. **应用**：按 `apps` 下的应用名（`app_name`）匹配。完全同名 → 唯一子串 → 多项弹窗 → 零命中列候选；不跨应用。
2. **表**：按 `tables` 的 `platform` 把用户词解析为稳定表 ID；请求时用该应用 `language` 对应的平台表，本地数据与脚本参数用稳定表 ID。不去别的应用找。
3. **字段**：按 `fields.<表>` 的 `platform` 把用户词解析为稳定字段 ID；请求时用当前语言的平台字段，本地数据与脚本参数用稳定字段 ID。未知字段拒绝。

## 边界

写入仅覆盖语义包登记的应用、表与字段；应用名为占位符（`TODO*` / `<...>`）时先索取真实编码与字段清单落盘，禁写入。分析结论不冒充写入。
