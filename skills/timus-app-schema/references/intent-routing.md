# 意图路由（通用版，唯一权威源）

`agents/*.md` 只保留「先判动作族，再选技能」的原则与 5 行实体表；**逐关键词映射以本文件为准**。
新增技能时只改本文件 + `plugin.json` 的 `skills`，不同步 agent md 的关键词清单。

## 第一原则：先判动作族

| 动词族 | 动作 | 技能 |
| --- | --- | --- |
| 建 / 新增 / 录入 / 建档 / 加 / 提交 / 登记 | 新建 | `record-create-form` |
| 查 / 搜 / 列出 / 详情 / 看一下 / 有多少 | 查询 | `record-maintenance` |
| 改 / 修改 / 更新 / 修正 / 改成 / 设置为 / 改状态 | 修改 | `record-maintenance` |
| 删 / 删除 / 移除 / 删掉 / 清掉 | 删除 | `record-maintenance`（二次确认） |

意图含糊（如「处理一下这条记录」）先弹一次选择框选动作，不猜测。
「记一笔 / 登记一笔」属新建，不归维护。

## 关键词映射（通用骨架）

| 用户关键词 | 技能 | 去向 |
| --- | --- | --- |
| 建 / 新增 / 录入 / 创建 / 提交 + 任一表名 | `record-create-form` | 由语义包围表匹配目标表 |
| 批量建 / 一次录多条 / 批量导入 | `record-create-form` | 多行模式（仅限无强序依赖的实体） |
| 查 / 搜 / 列出 / 详情 / 看一下 + 任一表名 | `record-maintenance` | `apaas_page_records` / `apaas_get_record` |
| 改 / 更新 / 修正 / 改状态 | `record-maintenance` | `apaas_edit_record`（查后唯一定位 + 确认） |
| 删 / 移除 / 清掉 | `record-maintenance` | `apaas_delete_record`（唯一定位 + 二次确认，不可撤销） |

## 表定位规则

用户说业务词时，按语义包 `tables` 的表单名匹配，匹配规则：

1. 完全同名 → 命中。
2. 用户说的是表名子串（如「流水」之于「收入流水」）且只命中一张表 → 命中。
3. 命中多张表 → 弹窗让用户选表，不猜。
4. 一张都没命中 → 列出语义包里的可用表名，请用户指定，不新造表名。

## 能力边界

- 写入能力仅覆盖语义包登记的表与字段；表不在语义包时先提示用户，不擅自扩展。
- 语义包未被填充真实字段前（仍是模板占位符），**不得进入写入流程**：先请用户提供应用编码与字段清单，落盘后再操作。
- 分析类结论不得冒充已落地的写入能力；查询结果足够时只回报，不臆造写回。
